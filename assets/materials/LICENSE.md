Each set includes color, OpenGL normal and roughness maps. Original 1K JPEGs
were verified against the provider's MD5 values and recompressed at quality 86.
`manifest.json` records exact download URLs, original MD5 values and the SHA-256
of each shipped file. No preview renders, logos or website artwork are included.
Only color maps use sRGB; normal and roughness maps are linear data.

The runtime loads these files locally. Poly Haven's API was used for download
metadata during preparation; the game does not access that API or hotlink images.
Thank you, Poly Haven, for the public-domain materials.

This applies to this texture pack only. Existing game code, Three.js, branding
and pre-existing assets retain their own licenses; they are not relicensed here.
